# PokEFREI-Showdown - Smart Pokemon Showdown Bot

PokEFREI-Showdown est un bot intelligent de combat pour la plateforme Pokémon Showdown développé en Python. Il prend en charge différents algorithmes décisionnels (heuristiques, minimax, expectiminimax avec équilibre de Nash, MCTS, Machine Learning et Deep Reinforcement Learning).

Pour plus de détails sur les objectifs du projet, l'architecture et les spécifications de chaque modèle, veuillez consulter le [Cahier des charges](./docs/cahier_des_charges.md).
